Game Night Artwork

Optional artwork can be added here without editing config/games.json.

Banner art:
  artwork/banners/<game-id>.png

Cover art:
  artwork/covers/<game-id>.png

The launcher also accepts .jpg, .jpeg, and .bmp files. The game id is shown in
config/games.json for curated games; auto-detected games use a cleaned-up id
based on the file name.
